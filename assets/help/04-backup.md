# Backup and restore

## Why backups matter

Kakeibo has no account and no cloud. Everything is on this phone. If the phone is lost, broken or reset, **a backup file is the only copy of your data**.

## Automatic weekly backup

Turn on **Settings → Data → Automatic weekly backup** and choose a folder, for example a **Kakeibo** folder inside **Download**. (Android doesn't allow the Download folder itself, so create a folder inside it.)

Once a week, when you open the app, Kakeibo saves a backup there and keeps the newest 8. Home reminds you if there's been no backup for 14 days.

## Back up now

**Settings → Data → Back up now**. Choose **Save to phone** to pick a folder, or **Share** to send it to Google Drive or email. The file is not encrypted: anyone who opens it can read your spending, so keep it somewhere private.

## Restore

**Settings → Data → Restore from a backup** and choose a Kakeibo backup file. The app checks the file, tells you what's in it, keeps a safety copy of your current data, and then replaces everything. It never merges.

A file from a newer version of the app is refused until you update.

## Export to a spreadsheet

**Settings → Data → Export spends** makes a CSV file with every spend: date, pillar, amount, note, mood and payment method.
